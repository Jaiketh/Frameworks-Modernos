# Documentação dos Arquivos do Projeto

## index.html
Arquivo HTML principal que estrutura a página web. Contém um formulário para busca de países e uma área para exibição dos resultados.

## paises.mjs
Módulo JavaScript que contém funções para manipulação e filtragem de dados dos países. Inclui:
- Funções para ordenação de países
- Filtros por continente e população
- Processamento de dados da API REST Countries

## script.js
Arquivo JavaScript principal responsável por:
- Integração com a API REST Countries
- Manipulação do DOM
- Gerenciamento de eventos do usuário
- Exibição dos dados dos países na interface

## style.css
Arquivo de estilos CSS que define:
- Layout e posicionamento dos elementos
- Cores e tipografia
- Responsividade da página
- Estilização dos cards de países
